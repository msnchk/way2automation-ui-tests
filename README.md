# Тест-кейсы для проверки UI сайта way2automation.com

### **TC-1. Проверка появления модального окна регистрации и функциональности кнопки "Register Now"**

**Приоритет**: Высокий (P1)

**Серьезность**: Значительная(S3)

**Предусловия:**

1. Открыта главная страница: https://www.way2automation.com
2. Пользователь не авторизован.

**Шаги**:

1. В течение 10 секунд ожидать появления модального окна.
2. Нажать во всплывшем окне кнопку "Register Now!"

**Ожидаемый результат**:<br>

1. Модальное окно появилось на странице.
2. Происходит переход на страницу: https://www.way2automation.com/lifetime-membership-club/
